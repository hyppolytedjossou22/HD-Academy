Maîtriser GitHub Copilot

Un cours complet pour programmer avec un assistant de code : l'utiliser pour avancer plus vite, comprendre ce qu'il écrit et continuer à progresser toi-même.

Chapitre 1. Comprendre ce qu'est GitHub Copilot

GitHub Copilot est un assistant de programmation qui s'installe dans un éditeur de code. Pendant que tu écris, il peut te suggérer la suite de ton code. Il propose aussi une zone de discussion où tu peux lui poser des questions sur ton code.

Comment il fonctionne, en simple

Copilot s'appuie sur un modèle d'IA entraîné sur de grandes quantités de code et de texte. Il regarde ce que tu as déjà écrit (le fichier, les commentaires, les noms de fonctions) et prédit ce qui est probablement la suite. Il ne comprend pas ton projet comme un développeur humain : il propose des suggestions plausibles, pas des garanties.

Ce qu'il peut faire

  • Compléter une ligne ou une fonction.
  • Expliquer un morceau de code que tu ne comprends pas.
  • Proposer une correction à partir d'un message d'erreur.
  • Suggérer des tests ou des commentaires.

Chapitre 2. Bien démarrer

  1. Crée un compte sur GitHub, le site officiel.
  2. Regarde sur la page officielle de Copilot quelle offre est disponible pour toi. Il existe parfois des offres gratuites ou pour étudiants : vérifie si tu es éligible.
  3. Installe un éditeur de code, par exemple Visual Studio Code.
  4. Ajoute l'extension officielle GitHub Copilot depuis l'éditeur, puis connecte ton compte GitHub.
  5. Ouvre un fichier et commence à écrire : des suggestions apparaissent en gris. Tu peux les accepter ou les ignorer, par exemple avec la touche Tab pour accepter.

Les offres et les fonctions de Copilot évoluent régulièrement. Vérifie toujours la page officielle.

Installe uniquement l'extension officielle depuis la boutique de ton éditeur. Méfie-toi des fichiers « Copilot gratuit » téléchargés sur des sites inconnus : ils peuvent contenir des virus.

Chapitre 3. Guider Copilot avec de bons commentaires

La qualité des suggestions dépend de ce que tu écris. Un commentaire clair au-dessus d'une fonction est une consigne.

Avant / après

Consigne floue :

// calcul

Consigne précise :

// Fonction moyenne(notes) : reçoit un tableau de nombres entre 0 et 20,
// retourne la moyenne arrondie à une décimale.
// Si le tableau est vide, retourne 0.

Les habitudes qui aident

  • Donne des noms clairs aux fonctions et aux variables.
  • Décris l'entrée (ce que la fonction reçoit) et la sortie (ce qu'elle retourne).
  • Mentionne les cas particuliers : tableau vide, texte vide, nombre négatif.
  • Garde ton fichier propre : un code désordonné donne des suggestions désordonnées.

Exercice 1. Écris le commentaire d'une fonction qui compte les mots d'un texte. Regarde la suggestion, puis améliore ton commentaire pour obtenir une meilleure version.

Chapitre 4. Comprendre et corriger avec le chat

Selon ton offre, tu disposes d'une zone de discussion avec Copilot. Elle est très utile pour apprendre.

Demandes utiles

Explique ce code ligne par ligne, avec des mots simples, comme si j'étais débutant.
J'obtiens cette erreur : [colle le message]. Explique-moi ce qu'elle signifie et ce que je dois vérifier, sans me donner directement la solution.
Propose 3 cas de test pour cette fonction, y compris des cas limites.

La méthode pour déboguer

  1. Lis le message d'erreur en entier, avec le numéro de ligne.
  2. Formule ton hypothèse : « Je pense que le problème vient de… »
  3. Demande à Copilot de la confirmer ou de la corriger.
  4. Teste ta correction et vérifie que le problème a disparu.

Exercice 2. Provoque volontairement une erreur dans un petit programme. Essaie de la comprendre seul, puis demande à Copilot de l'expliquer sans donner la solution. Compare vos explications.

Chapitre 5. Apprendre à programmer sans perdre tes compétences

Le piège, c'est d'accepter tout ce que l'outil propose sans comprendre. Tu avances vite, mais tu n'apprends pas.

La règle des 4 temps

  1. Réfléchis : quelle est ta solution ? Écris ton plan en commentaires.
  2. Essaie : écris une première version seul.
  3. Compare : regarde la suggestion de Copilot et demande-toi ce qu'elle fait de mieux ou de différent.
  4. Explique : tu dois pouvoir expliquer chaque ligne que tu gardes.

Un test simple

Efface la suggestion et réécris la fonction de mémoire quelques jours plus tard. Si tu n'y arrives pas, c'est que tu as copié sans comprendre.

Les bases d'abord

Continue à apprendre HTML, CSS et JavaScript par la pratique. Copilot aide un développeur qui comprend les bases, il ne les remplace pas.

Exercice 3. Choisis un exercice simple, par exemple inverser un mot. Applique la règle des 4 temps et écris trois lignes qui expliquent comment fonctionne la version finale.

Chapitre 6. Limites, sécurité et bonnes pratiques

  • Code faux : une suggestion peut sembler correcte et contenir une erreur. Teste toujours.
  • Fonctions inventées : il peut proposer des fonctions ou des bibliothèques qui n'existent pas. Vérifie dans la documentation officielle.
  • Failles de sécurité : un code généré peut être vulnérable. Sois prudent avec les mots de passe, les formulaires et les bases de données.
  • Secrets : ne mets jamais de mots de passe, clés d'accès ou jetons dans ton code ni dans tes questions.
  • Licences : respecte les règles de licence du code que tu réutilises.
  • Projets d'école : respecte les consignes de ton enseignant sur l'utilisation de l'IA.

Chapitre 7. Projet final

Projet. Crée une petite page web « Calculateur de moyenne » :
1. Fais un plan en commentaires : champs de saisie, bouton, résultat.
2. Écris toi-même le HTML de base.
3. Utilise Copilot pour t'aider avec la fonction JavaScript qui calcule la moyenne, en écrivant d'abord un commentaire précis.
4. Teste avec au moins cinq cas : notes normales, une seule note, aucune note, note négative, note supérieure à 20.
5. Corrige les cas qui échouent.
6. Explique ton code, ligne par ligne, à quelqu'un d'autre.

À retenir

  • Copilot suggère, c'est toi qui décides.
  • Un commentaire clair donne de meilleures suggestions.
  • Teste et comprends chaque ligne que tu gardes.
  • Protège tes secrets et continue à apprendre les bases.
